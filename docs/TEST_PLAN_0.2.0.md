# Market Radar 0.2.0 测试计划

对应 [0.2.0 开发计划](DEV_PLAN_0.2.0.md) 的 3 个 Phase。按功能提交验证，用同一套回归样本在本地 `test` 验收。

## 测试准备

- 在本地临时目录复制 `v0.1.0`（`3b5cc0f`）的 JSONL、CSV 和立项档案，用旧版结构准备 SQLite 测试库。记录基线条数、证据 ID 和原文链接。
- 使用固定基准时间、带时区的时间样本、旧帖及评论样本。导入、归档和导出在临时目录验证。

## 本地验收结果

2026-11-25，本地验收覆盖功能提交 `1b9ca01`。

- **单元测试。** `python -B -m unittest discover -s tests -v` 共 16 项通过，采集提交单独验证时 8 项通过。
- **浏览器。** 用隔离临时库生成本地 HTML。Edge 无头模式验证排序切换、两层时效卡片、第一列的完整时间戳、原帖展开和回环地址上的测试主页。
- **样本范围。** 采集排序使用模拟源站响应，评论及标签使用离线样本。实际站点可用性和公开画像字段覆盖率待持续采集评估。

### 归档日期口径复验

用原归档生成预览，1,331 条有效旧信号均按原 `published_at` 分档并显示「归档标记」，「时间待核实」由 1,331 条降为 0 条。Edge 验证这批旧信号均未计入「近 24 小时」。
