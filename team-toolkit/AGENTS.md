# 团队统一 AI 协作规范 (Codex CLI / DeepSeek Harness 通用模板)

> 将本文件复制到团队任何新项目的根目录下（命名为 `AGENTS.md`），即可让所有成员的 Codex CLI 与 DeepSeek Harness 自动遵循统一工程规范。

## 1. 核心工作流原则
- **先读后写，小步验证**：修改代码前先通过检索确认上下文与已有调用链；每次修改后立即运行最小可验证命令，确认无语法或运行时错误。
- **拒绝过度设计**：优先使用标准库与成熟轻量方案跑通业务闭环，不引入非必要的重型中间件。
- **多人协作无冲突**：不在 Git 仓库中直接提交二进制数据库（如 `*.db`）或个人本地缓存目录（如 `.browser_profile/`），统一使用按行追加的 `.jsonl` 或按模块拆分的独立 `.json` 配置文件。

## 2. 模型调用与成本控制约定
- **主力推理底座**：默认使用 `DeepSeek-V4.1-Flash` 处理高频文本提取、结构化 JSON 生成、分镜脚本拆解与日常编码辅助。
- **开启前缀缓存（Context Caching）**：构造 Prompt 时将固定系统指令、长文档背景与 Few-shot 示例置于最前方，动态用户输入置于末尾，最大化命中前缀缓存以降低 Token 消耗与首字延迟。

## 3. 中文文档与沟通规范
- 保持平实、准确、克制的工程中文；避免使用夸张修饰词、自造黑话或装饰性 Emoji。
- 汇报与方案说明遵循“结论 → 原因/依据 → 具体动作與边界”结构，区分已验证结果与待测试假设。
